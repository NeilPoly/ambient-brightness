# 板子程序

微雪 ESP32-C3-Zero + 三块 OPT3001：读照度 → 按曲线算目标亮度、学你手动调的点 → 通过 Wi-Fi 调 Mac 上 BetterDisplay 的 HTTP 接口。

## 编译、升级

在这个目录：

- 编译：`pio run`
- 插 USB 烧：`pio run -t upload`
- 不插 USB 升级：设置页上传 `.pio/build/c3zero/firmware.bin`，或者 `curl -F firmware=@.pio/build/c3zero/firmware.bin http://ambient.local/update`。写进另一半闪存，成功了重启换过去；设置、学到的点、记录都不丢。
- Apple 芯片的 Mac：这个平台带的编译器是 Intel 版，装 Rosetta，或者在 `platformio.local.ini`（不进 git）里指向乐鑫的 arm64 版，写法见 `platformio.ini` 的注释。

## 文件

| 文件 | 内容 |
|---|---|
| `src/main.cpp` | 开机、主循环：读传感器、串口命令、网页 |
| `src/sensors.cpp` | 三块 OPT3001（软件 I2C，地址脚悬空的处理） |
| `src/brain.cpp` | 调节算法：合成和平滑照度、曲线、学到的点 |
| `src/control.cpp` | 调节任务：每 0.1 秒往目标走、每 3 秒读亮度、发现手动调节、什么时候先不调 |
| `src/bd.cpp` | BetterDisplay 的 HTTP 接口（按 `xxx.local` 找 Mac） |
| `src/net.cpp` | Wi-Fi、配网热点、mDNS、对时间 |
| `src/web.cpp` | 网页和接口 |
| `src/logbook.cpp` | 记录（闪存里转圈存 7 天） |
| `src/settings.cpp` | 设置（存在闪存里） |
| `web/` | 板子上的三个网页：`monitor.html`（读数）、`settings.html`（设置）、`wifi.html`（配网） |
| `embed_web.py` | 编译前把 `web/` 的网页压缩进固件 |

## 网页

- http://ambient.local ：三路照度、各台亮度、曲线和学到的点、自动调节开关。
- http://ambient.local/settings ：曲线、上下限、调节速度、三路权重、调哪几台、Mac 的地址；Wi-Fi；下载记录；上传固件。保存就生效。
- 直接双击打开 `web/monitor.html`：用 Chrome 读板子的 USB 串口，只看读数，排查问题用。

## Wi-Fi 和配网热点

- 只能连 2.4 GHz。
- 没配过 Wi-Fi：开热点 `Ambient-xxxx`，不要密码。手机连上会弹出配网页（或者打开 http://192.168.4.1）。
- 配过、但连不上超过 10 分钟：开同名热点，要密码。密码是第一次开机随机生成的 8 位数字，设置页上能看到，USB 串口开机时也会打出来。
- 从热点连进来只能配 Wi-Fi，改不了设置、传不了固件、下载不了记录。连回家里 Wi-Fi 2 分钟后热点自己关掉。
- 发射功率 8.5 dBm：这块板子开满功率时，热点连得上、网页打不开。
- 开了 IPv6：不开的话，Mac 上 Chrome 按名字打开 `ambient.local` 每次要等 5 秒。

## 调节规则

1. 三路照度按权重对 log 照度加权平均，合成一个照度，再按"照度平滑"的时间平滑。
2. 合成照度按基础曲线查出目标亮度（点和点之间按 log 照度连直线），加上各台的偏移，限制在最低～最高亮度之间。默认最低 50%：BetterDisplay 50% 以下是软件压暗，背光已经最低了。
3. 每 0.1 秒算一次。差到"差多少才开始调"才开始，调起来每秒最多变"每秒最多变"，按 1% 一格发给显示器，一直跟到目标。
4. 每 3 秒读一次各台亮度。和板子发的对不上，就当作你手动调的：把（当时的照度，你调到的亮度）记成学到的点，超出上下限的按边界记。
5. 实际曲线 = 基础曲线 + 学到的点的修正：每个点的偏差按钟形权重往两边摊（"影响范围"），曲线正好经过学到的点，照度越高亮度不会越低。附近（"替换范围"）的旧点和矛盾的旧点会被新点替换。
6. 多台显示器：在 BetterDisplay 里设成一组、打开同步，设置页里只勾一台。同步传的是变化量：调一台，另外几台加减同样多。

## 什么时候先不调

网页上"自动调节"按钮后面会写原因：Wi-Fi 没连上、还没填 Mac 的地址、还没选要调哪台显示器、连不上 BetterDisplay、有一台显示器读不到、显示器睡着、刚恢复（等 10 秒）、没有照度读数。先不调的时候读到的亮度只当起点，不算手动调节。

显示器睡没睡：读第一台要调的显示器的 DDC 电源状态（VCP 0xD6）。睡着时读不到（BetterDisplay 回 404），醒着时偶尔也读不到，所以连着两次读不到才算睡着。分组同步传不到睡着的显示器，睡着时调了，醒来几台就会差开。

## 供电和记录

- 插显示器的 USB 口，显示器设置里让 USB 在待机时也供电（DELL 叫"待机期间开启"），显示器睡着时照样记录。
- 记录每分钟一行，闪存里存 7 天，网页上能下载。
