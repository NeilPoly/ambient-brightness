照度 → 亮度

一行一个点：照度（lux）和亮度（%），照度从低到高。点和点之间按对数照度连直线，最左、最右的点以外保持不变；再限制在最低～最高之间。你手动调亮度学到的点另外叠加，不改这里。

BetterDisplay 的 50% 是显示器自己的亮度 0，往下是软件压暗（画面发灰）。

调节

三块传感器

三路照度按权重对数加权平均，合成一个照度。先只用正面 A（和手机的光线传感器一样朝着人）。

学你手动调的亮度

按"差几个十倍照度"算。影响范围 0.5：差 3 倍照度时还剩 61% 的影响，差 10 倍剩 14%。替换范围 0.3 ≈ 2 倍照度以内的旧点会被新点替换。

显示器

编号是 BetterDisplay 里的 tagID（在 Mac 上打开 http://localhost:55777/get?identifiers 能看到每台的 tagID）。BetterDisplay 开着分组同步时只勾一台，另外几台靠同步跟着走（同步传的是变化量：调一台，另外几台加减同样多）。编号空着就是没有这一行。

Mac 上的 BetterDisplay

BetterDisplay 设置 → Application → Integration 里打开 HTTP 接口。地址可以写 IP，也可以写 Mac 的名字加 .local（Mac 换了 IP 也能找到）。

时区用 POSIX 写法：中国 CST-8，日本 JST-9。
